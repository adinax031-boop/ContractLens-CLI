# Security

Do not post secrets or private contracts in public issues. For a suspected vulnerability, use GitHub's private vulnerability reporting if enabled on this repository; otherwise contact the repository owner privately through a channel on their GitHub profile before public disclosure.

Version 1.x is the current supported line. ContractLens reads local JSON and writes local output; it does not fetch remote references. It does not execute examples or contract content. Generated HTML escapes finding text and has no JavaScript. Treat API contracts and reports as potentially confidential. Run hostile or oversized documents inside resource-limited jobs. Structural analysis is not full specification validation or a security audit.
